# Orientation Analysis

This module measures glycan orientation diversity before or after placement.

## Analyze a Library

```bash
python -m fast_glycan_masking.analysis.orientation \
    --library Man5_library.npz \
    --out-prefix results/Man5_library
```

This describes the orientation diversity available in the conformer library.

## Analyze Placed Conformers

```bash
python -m fast_glycan_masking.analysis.orientation \
    --placed Glyc_A581_placed.npz \
    --protein target.pdb \
    --site A:581 \
    --out-prefix results/A581
```

`--placed` expects the `*_placed.npz` generated by the placer, not the placement output directory.

## Reported Metrics

Current analysis includes metrics such as:

- nearest-neighbor angular separation
- sampled pairwise angular separation
- occupied orientation bins
- occupancy fraction
- normalized entropy

These metrics should be interpreted together. For example, a large library can have small nearest-neighbor angles while still spanning a broad overall orientation range.

For the definitions and interpretation of these metrics, see `docs/ORIENTATION_DIVERSITY.md`.
