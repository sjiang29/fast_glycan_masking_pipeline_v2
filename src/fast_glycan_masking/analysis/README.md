# Orientation Analysis

This module measures glycan orientation diversity before or after placement. It supports analyzing all available conformers or a randomly selected subset for faster analysis and visualization.

## Analyze a Library

Analyze the entire conformer library:

```bash
python -m fast_glycan_masking.analysis.orientation \
    --library Man5_library.npz \
    --out-prefix results/Man5_library
```

Analyze 200 randomly selected conformers:

```bash
python -m fast_glycan_masking.analysis.orientation \
    --library Man5_library.npz \
    --out-prefix results/Man5_200 \
    --n-conformers 200 \
    --seed 2026
```

The `--n-conformers` argument specifies the number of conformers to analyze. When omitted, all conformers are analyzed.

The `--seed` argument controls random sampling for reproducibility (default: `2026`). The original library indices of sampled conformers are preserved in the orientation CSV output.

## Analyze Placed Conformers

Analyze all placed conformers:

```bash
python -m fast_glycan_masking.analysis.orientation \
    --placed Glyc_A581_placed.npz \
    --protein target.pdb \
    --site A:581 \
    --out-prefix results/A581
```

Analyze 200 randomly selected placed conformers:

```bash
python -m fast_glycan_masking.analysis.orientation \
    --placed Glyc_A581_placed.npz \
    --protein target.pdb \
    --site A:581 \
    --out-prefix results/A581_200 \
    --n-conformers 200 \
    --seed 2026
```

`--placed` expects the `*_placed.npz` generated by the placer, not the placement output directory.

## Sampling Options

| Argument | Description | Default |
|---|---|---|
| `--n-conformers N` | Randomly select N conformers for analysis | All conformers |
| `--seed SEED` | Random seed for reproducible selection | `2026` |

Sampling is performed without replacement. If `--n-conformers` is omitted, the script analyzes the full dataset.

## Generated Outputs

The module generates:

- **Orientation CSV:** Normalized direction vectors, azimuth angles, polar angles, and conformer identifiers.
- **Azimuth histogram:** Distribution of glycan orientations around the Z-axis (0–360°).
- **Polar-angle histogram:** Distribution of glycan orientations relative to the positive Z-axis (0–180°).
- **Spherical occupancy plot:** Two-dimensional orientation distribution using azimuth and cosine of the polar angle.
- **JSON summary:** Orientation diversity statistics and occupancy metrics.

For library analysis, orientations are calculated using the vector from ASN ND2 to either the whole-glycan geometric center or the root glycan C1 atom, when available.

For placed conformers, orientations are calculated from ASN ND2 to the whole-glycan geometric center.

Angles are measured relative to the coordinate axes of the input structures.

## Reported Metrics

Current analysis includes metrics such as:

- Nearest-neighbor angular separation
- Sampled pairwise angular separation
- Occupied orientation bins
- Occupancy fraction
- Normalized entropy

These metrics should be interpreted together. For example, a large library can have small nearest-neighbor angles while still spanning a broad overall orientation range.

When using `--n-conformers`, the reported metrics describe only the selected subset, not the entire library.

For the definitions and interpretation of these metrics, see `docs/ORIENTATION_DIVERSITY.md`.
